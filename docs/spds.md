# СПДС в CADCraft Mobile: техническое задание

Собрано 2026-10-19 по рабочей исполнительной схеме пользователя (nanoCAD СПДС 24.1, «Исполнительная
схема Пер-Ф1 Отделка поверхности фасада переходов», лист А3) и по меню СПДС nanoCAD, осмотренному
как пользователь. Файлы, библиотеки и код nanoCAD не используются: всё рисуется заново по ГОСТ.

## Что есть на реальной исполнительной схеме

| Элемент | Как выглядит | Нормы |
|---|---|---|
| Координационные оси | Красные линии, марки в кружках; марки дробные (`6/3`, `А/3`, `Б/5`) | ГОСТ Р 21.101 |
| Отметки уровня (фасад) | Текст `+6,330`, `0,000`, `−0,150` в рамке над полкой, выноска со стрелкой 45° к уровню; слой `СПДС_СИМВОЛЫ` | ГОСТ Р 21.101 |
| Размеры | Цепные, засечки, синие | ГОСТ 2.307 |
| Марки проёмов | `Ок-7`, `Д2` в проёмах | ГОСТ Р 21.501 |
| Заголовки | «Исполнительная схема …» подчёркнуто, названия видов «Фасад 6/3-4» | |
| Штриховки | Грунт (косая под линией земли), точечная заливка «оштукатуренный фасад» | ГОСТ 2.306, Р 21.501 |
| Условные обозначения | Таблица: образец штриховки или линии и подпись | |
| Подтверждение | «Схема соответствует фактически выполненным работам. Начальник участка … ____ ФИО» над штампом | ГОСТ Р 51872 |
| Основная надпись | Форма 3, 185×55: Изм/Кол.уч/Лист/№ док/Подп/Дата; строки «Разработал», «Нач. участка»; объект; раздел; Стадия `ИД`, Лист, Листов; наименование; организация; «Формат А3» под рамкой | ГОСТ Р 21.101 |

| Листы | Пространство листа, видовые экраны 1:100 | |
| Шрифт | ГОСТ 2.304 тип А, наклонный | |

## Объекты в меню СПДС nanoCAD (что существует)

- **Оси:** отдельная ось, дуговая, круговая; дополнительные маркеры; подобные оси;
  переименование осей; раздвинуть маркеры; сетка осей.
- **Отметки уровня:** отметка уровня (фасад/разрез), отметка на плане; пересчёт
  неассоциативных отметок; выравнивание по стрелкам и по базам.
- **Выноски:** позиционная, гребенчатая, цепная, узловая, узловая секущая, для многослойных
  конструкций, маркировка линейных конструкций, диапазон распределения; добавить, удалить,
  перецепить линию-выноску.
- **Обозначения:** уклон, узел, фрагмент, маркер изменения, позиционный маркер, позиция, пикетаж;
  разрезы и сечения, виды, обозначения видов и разрезов.
- **Разрывы:** линейный и криволинейный обрыв и разрыв, цилиндрический обрыв, разорвать размер.
- **Текст:** СПДС-текст, технические требования, технические характеристики.
- **Сварка:** неразъёмные соединения, катет, шов, соединение, разделка кромок.
- **Штриховки:** граничная, штриховая полоса, теплоизоляция, гидроизоляция, граница грунта.
- **Форматы:** форматы со штампами, обложки и титульные листы; таблицы.
- **Архитектура и сети:** помещения, площади, экспликации, стены, окна; оборудование, трассы.
- **Размеры СПДС:** линейный, параллельный, угловой, диаметр, радиус, дуговой, ординатный.

## Очерёдность для исполнительных схем

1. Формат А4–А1 с основной надписью формы 3 и дополнительными графами; блок «Схема соответствует…».
2. ГОСТ-шрифт тип А (наклонный).
3. Оси: отдельная ось с маркером (в том числе дробные марки), сетка осей.
4. Отметка уровня (фасад/разрез) в варианте пользователя: значение в рамке, со знаком.
5. Граница грунта, теплоизоляция, гидроизоляция; таблица «Условные обозначения».
6. Обозначения разрезов, видов, узлов; позиционная выноска.
7. Отклонения по ГОСТ Р 51872: стрелка + мм, факт/проект.
8. Остальное по запросу.

Объекты сохраняются как обычные блоки с атрибутами на слоях `СПДС_*`, поэтому файлы читаются
в nanoCAD и AutoCAD без надстроек.
